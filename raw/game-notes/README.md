# Game Notes Drop Zone

Drop any Super Snail game knowledge here as .md files.
Files are automatically compiled into wiki/game/ articles twice daily.

## File naming

Use descriptive names: arena-tips.md, relic-tier-list.md, club-war-strategy.md

## Format

Plain markdown. Can be rough notes, copy-paste from Discord, or structured guides.
The auto-compiler will extract and structure the knowledge.

## After compilation

Raw files stay here (as source reference). Wiki articles appear in wiki/game/.
