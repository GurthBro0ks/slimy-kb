# Import Policy

## Default stance

Nothing from the Super Snail extraction workspace is allowed into this repository by default.

## Allowed immediately

- hand-written documentation
- empty scaffolding
- scripts with no secrets
- proof summaries
- prompts
- redacted reports

## Blocked by default

- APK/XAPK files
- `.luac` files
- packet captures
- account/session/token/cookie files
- raw MITM flows
- private game account data
- contaminated v2 decode outputs
- any file generated by scripts that overwrite source evidence

## Proof-gated imports

Files may only be imported after a proof directory contains `RESULT.md` with a clear status and the operator approves the import.

## Required proof metadata for imports

Imported reports should reference:

- source proof directory
- UTC timestamp
- sha256 hashes
- trust status
- unresolved conflicts
- known contamination risks
